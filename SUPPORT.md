# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/github/gh-elm/issues) to
track reproducible bugs and feature requests. Please search the existing
issues before filing a new one to avoid duplicates.

For usage questions and general feedback, use
[GitHub Discussions](https://github.com/github/gh-elm/discussions). For
customer-specific migration or GitHub Enterprise Server assistance, contact
[GitHub Enterprise Support](https://support.github.com).

`gh-elm` is under active development and maintained by GitHub staff with help
from the community. We will do our best to respond to issues, feature requests,
and community questions in a timely manner, but response times are not
guaranteed.

## GitHub Support Policy

Support for this project is limited to the resources listed above.
